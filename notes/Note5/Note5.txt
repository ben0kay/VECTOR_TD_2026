Tomorrow notes — New Vector performance vs Old Vector
Old Vector is faster mainly because enemies do very little most frames.
Expensive work is timer/flag-driven instead of every Step.
Offscreen enemies use much larger lazy intervals for target/path decisions.
Native paths keep moving enemies without constantly rebuilding or re-evaluating everything.
Visual facing only updates when visibility logic says it matters.
Visibility itself is staggered.

For New Vector, aim for this execution model:

Every frame: only essential movement, cooldowns, active attack behavior, truly necessary state.
Every few frames, staggered: current target validity, range checks, LOS checks, visual-facing updates if needed.
Every 10–30+ frames: strategic retargeting, player-target reconsideration, visibility/performance checks.
Flag/event only: path rebuilds, nav revision reactions, breach attempts, new target acquisition.
